# BDVM - Full

Installable composition bundle for the BDVM modules. It owns Unity/UI composition only; feature domain sources remain in their respective module repositories.

The optional SelfShunt integration is based on the authorized fork of https://github.com/Chump-the-Lump/DV-SelfShunter at commit `329c85cf51715404af3b4d455239d9fc54f5ac5b`. Credit: `Chump_the_Lump`. No conventional upstream license file was observed; distribution relies on the author’s fork permission and must retain this attribution.

No compatibility facade or old checkpoint import is shipped.
